# Supplementary material

Anonymous supplementary material for an ICLR 2027 submission.

## Figures

- `figures/human_study.png` (also as PDF): the four-question human study. Four raters each rated all 200 pairs, 40 per comparison. Each column is one comparison, each row one question, and each bar gives the case-weighted share of judgments preferring SRA (win 1, tie 0.5, loss 0), so 50 means no preference.
